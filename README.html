GitHub Less Social ══════════════════

I don’t wish to use the proprietary code forge, but when I do I want less social features in my face trying to get me to ‘engage’. This filter list looks to hide features that involve distractions and clutter on the platform. The base list tries to clean up the feeds quite a bit, pushing some of the bright colors and button to when you actually click into the item for a detail view.

To give GitHub some credit, it’s because they do a decent job with aria-* tags for accessibility and sane markup that the filter list gets to be concise.

Tip
 Do encourage projects to migrate to or support mirrors on open source code forges like the one here on SourceHut.

Usage

It’s required that you start with an ad blocker add-on that supports filters. My suggestion is uBlock Origin which is available on many platforms and the following instructions are only for this add-on.

To add GitHub Less Social filter list

  1. Open uBlock Origin’s settings

  2. Go to “Filter lists”

  3. Scroll to the bottom of the list to “Custom”

  4. Enable “Import…” if not checked already

  5. Add https://git.sr.ht/~toastal/github-less-social/blob/trunk/list.txt to a new line

  6. Click the big check mark button in the actions bar to apply

For a more aggressive option (more likely to hide things you may want to see), use https://git.sr.ht/~toastal/github-less-social/blob/trunk/aggressive.txt instead.

Warning
 Don’t use Google Chrome. Firefox, Librewolf, Brave, and all the others are a better option. If you’re concerned about ads, you should be aware that Google’s entire browser is adware.
